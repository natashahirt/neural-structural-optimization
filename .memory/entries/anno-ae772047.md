Making CLIP_AVAILABLE lazy so `--print-config` does not import clip/kornia is correct. Making torch lazy is not: if torch loads after a CHOLMOD solve has run in the process, the suite dies on a bare SIGSEGV (no traceback). Eager `import torch` in package `__init__.py` immediately after `OMP_NUM_THREADS=1` keeps CLIP lazy and torch early. Do not make `structural/__init__.py` stop importing `api` for the same reason.
