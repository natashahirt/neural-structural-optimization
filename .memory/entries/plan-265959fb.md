StructuralParams carries filter_width, rmin, beta, heavyside, and eta, but none reach physics. get_problem() filters arguments to the problem function's signature, the Problem dataclass has no such fields, and specified_task reads them via getattr(problem, 'filter_width', 2.0). So rmin=0.25, filter_width='linear', and beta='linear' in script/run.py do nothing, and neither does the per-stage scaling in model_base.

Two defects currently mask each other: fixing propagation alone sends the string 'linear' into cone_filter, where np.ceil raises TypeError. Schedule strings must resolve to per-stage floats before physics.

The projection restructure is the risky part. Volume enforcement must move to the END of the chain (sigmoid, mask, filter, projection, enforcement). The cone filter is column-normalized so it preserves total sum and volume survives filtering, but Heaviside projection is mean-breaking, so appending it to the current ordering would violate volfrac silently.

Behavior-preserving by default: heavyside=False and filter_width=2.0, matching what Venice actually ran, so stage 3 parity stays reachable. Projection is opt-in.

Known hazards for the implementer:
- Cost: moving enforcement to the end puts the cone filter inside find_root's bisection loop, which runs up to 64 iterations. Currently the residual is only a sigmoid and a mean.
- Silent failure: the existing bracket logit(average)-max(x) to logit(average)-min(x) is derived for the plain sigmoid. A post-projection residual needs new bounds, and bisection with a bad bracket converges to a bound without raising.
- find_root's reverse-mode gradient is now verified by test_find_root_grad (repaired in stage 0), and grad_find_root applies the implicit function theorem to an arbitrary residual, so only a new residual and bounds are needed.
- rmin is doubly dead: stored in args but physical_density only reads filter_width.

Gate: with projection off, compliance is unchanged from before the restructure. With projection on, volfrac still holds (to ~1e-9; it currently holds to ~1e-15).
