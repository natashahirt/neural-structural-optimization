Two-pass distillation from a converged CLIP teacher cannot reorganize where structure sits. Stage 6 occupancy worked because the map existed before optimization, independent of the default gothic frame. A finished teacher is already that frame plus motif decoration; extracting a scaffold from it and initializing the student from teacher z only copies (then degrades) a locked layout. Layout has to be decided before members lock — a motif envelope from a non-structural or early/coarse CLIP field, then a structural run grown into it from the usual coarse start, not a second pass on the teacher.
