Occupancy cut is a fixed 0.40 on inverted grayscale (ink=1), not Otsu and not a learned threshold.

Measured on the six-sketch corpus at native resolution: median inverted ink is 0.00–0.13 (paper), p90 is 0.73–0.98 (strokes). At 0.40, occupancy fractions are 1: 0.135, 3: 0.198, 6: 0.212, 9: 0.148, 11: 0.316, 12: 0.219 — around a 0.3 volfrac, with faint grids/ghost rectangles below the cut. 0.50 is similar; 0.20 starts picking up construction. Same value lives in `SketchConfig.threshold` and `DEFAULT_OCCUPANCY_THRESHOLD`. Optional `blur_sigma` can soften the stencil later; default 0 keeps the binary map.
